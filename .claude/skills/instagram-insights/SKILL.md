# 인스타그램 성과 분석·운영 조언

## 데이터 가져오기
```bash
cd instagram && python -m igtool insights --days 7 --posts 12
```
`instagram/out/insights-*.md` (Claude 분석 리포트)와 `insights-*.json` (원본 수치)이 생긴다. 기간은 `--days 30` 처럼 바꿀 수 있다.
토큰이 없으면 사용자에게 인스타그램 앱의 "프로페셔널 대시보드 → 인사이트" 화면 캡처를 받아 그걸로 분석한다.

## 사용자에게 전달
- 리포트를 그대로 붙여넣지 말고 핵심만 요약한다: 숫자 3~5개, 잘된 것/아쉬운 것, 이번 주 할 일.
- 수치를 비교할 때는 직전 리포트(`out/` 의 이전 파일)가 있으면 변화량을 함께 보여준다.
- 시각적으로 보고 싶어 하면 차트를 그린다(dataviz 스킬 사용).

## 조언 원칙
- 데이터에 근거한다. 표본이 적으면(게시물 5개 미만 등) 그렇다고 밝힌다.
- 참여율 = (좋아요 + 댓글 + 저장 + 공유) ÷ 도달. 저장과 공유는 알고리즘에서 특히 중요하다.
- 실행 가능한 형태로 말한다: "릴스를 더 올리세요"가 아니라 "화·목 저녁 8시에 15초 릴스, 첫 자막에 질문형 후킹".
- 팔로워 구매, 맞팔 자동화, 비공식 자동화 툴처럼 계정 정지 위험이 있는 방법은 권하지 않는다.
