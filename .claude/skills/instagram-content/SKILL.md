# 인스타그램 콘텐츠 기획·제작

## 먼저 할 일
1. `instagram/brand.md` 를 읽는다. 비어 있는 항목이 많으면, 작업을 시작하기 전에 계정 주제·타깃·말투 3가지만 짧게 물어보고 brand.md 에 채워 준다.
2. 계정 데이터가 필요하면(아이디어 추천, "잘 되는 걸로" 같은 요청) `instagram/.env` 에 `IG_ACCESS_TOKEN` 이 있는지 확인하고
   `cd instagram && python -m igtool insights --days 30` 으로 최근 성과를 가져와 근거로 쓴다. 토큰이 없으면 데이터 없이 진행하고 그렇다고 말한다.

## 산출물 형식
- **아이디어**: 형식(릴스/캐러셀/단일/스토리) · 제목 · 첫 1초 후킹 문구 · 구성 · 캡션 초안 · 해시태그 · 추천 업로드 시간 · 고른 이유
- **캡션**: 첫 줄은 피드에서 잘리기 전에 읽히는 후킹 문장(약 40자 이내). 본문은 줄바꿈으로 읽기 쉽게, 마지막에 댓글을 유도하는 질문.
  톤 다른 버전 2~3개를 제안한다.
- **해시태그**: 10~15개. 대형(100만+), 중형(1만~100만), 소형/지역 태그를 섞는다. brand.md 의 고정 해시태그를 포함한다.
- **릴스 대본**: 0~3초 후킹 / 본론 장면별(화면, 자막, 대사) / 마지막 CTA. 15~30초 기준.
- **캐러셀**: 슬라이드별 제목과 문구. 1장은 후킹, 마지막 장은 저장·공유 유도.
- **콘텐츠 캘린더**: 요일 · 형식 · 주제 · 목적(도달/참여/전환) 표.

## 업로드
사용자가 업로드를 원하면, 이미지나 영상이 **공개 URL** 이어야 한다(Instagram API 제약). 캡션을 파일로 저장하고 먼저 확인용으로 실행한다.
```bash
cd instagram
python -m igtool publish --image URL --caption-file caption.txt --dry-run
```
사용자가 확인하면 `--dry-run` 을 빼고 실행한다. 업로드는 되돌릴 수 없으므로 매번 확인을 받는다.
`--image` 를 여러 번 쓰면 캐러셀, `--video URL` 은 릴스다.
